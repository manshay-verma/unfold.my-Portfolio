BMP Book – Pandit Booking Platform

Project Type Mobile App + Backend
Role Full-Stack Developer
Domain Service Marketplace
Platform iOS & Android

Key Features

  • React Native mobile app
  • DRF backend APIs
  • AWS SNS & SQS integrations
  • Redis caching
  • Geolocation & maps
  • Real-time notifications
  • Booking workflows
  • Elasticsearch search systems

Tech Stack

React Native Django REST Framework AWS SNS AWS SQS Redis Elasticsearch Python
